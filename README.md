# 📚 교보문고 (만화책 뷰어) - Manga Viewer

웹툰 및 만화책 감상에 최적화된 고성능 안드로이드 뷰어 어플리케이션입니다. 실시간 스트리밍뿐만 아니라 사전 다운로드 및 로컬 ZIP 파일 지원을 통해 언제 어디서나 최상의 독서 경험을 제공합니다.

---

## ✨ 핵심 기능 (Features)

### 1. 스마트 웹 파싱 및 탐색
*   **카테고리 분류**: 완결만화, 인기만화, 최신만화, 매일 추천 100 등 다양한 카테고리 지원.
*   **무한 스크롤 (Infinite Scroll)**: 리스트 하단 도달 시 자동으로 다음 페이지를 로드하여 끊김 없는 탐색 가능.
*   **고도화된 검색**: 키워드 검색 지원 및 키보드 엔터키 연동. 검색 결과가 없을 경우 명확한 안내 메시지 표시.

### 2. 전문적인 만화책 뷰어 (Viewer)
*   **다양한 보기 모드**: 
    *   **한장보기**: 스마트폰 세로 화면에 최적화.
    *   **두장보기**: 태블릿이나 가로 화면에서 실제 책처럼 두 페이지씩 감상.
    *   **나눠보기**: 가로가 긴 이미지를 반으로 나누어 크게 감상.
*   **몰입형 전체 화면**: 상단바와 하단바를 숨기고 화면 가득 이미지 노출.
*   **핀치 투 줌 (Pinch-to-Zoom)**: 두 손가락으로 자유로운 확대/축소 및 드래그 이동 지원. 확대 시 실수로 페이지가 넘어가지 않도록 스크롤 잠금 기능 포함.
*   **직관적인 내비게이션**:
    *   화면 좌/우 터치 및 스와이프를 통한 페이지 이동.
    *   하단 컴팩트 슬라이더를 통한 빠른 페이지 점프.
    *   회차 종료 시 **'다음 회차 바로 보기'** 팝업 안내.

### 3. 강력한 오프라인 및 로컬 지원
*   **내 보관함 (다운로드)**: 선호하는 회차를 기기에 사전 다운로드하여 비행기 모드 등 오프라인 상태에서 즉시 감상.
*   **로컬 ZIP 뷰어**: 기기에 소장 중인 만화책 ZIP 파일을 직접 열기 기능.
    *   **재귀적 탐색**: ZIP 내부의 폴더 구조는 물론, **ZIP 안에 또 다른 ZIP**이 있는 복잡한 구조도 자동으로 풀어서 이미지 정렬.
*   **데이터 관리**: 보관함 내 회차별 삭제 및 용량 관리 기능.

### 4. 사용자 설정 및 유연성
*   **동적 Base URL 설정**: 웹사이트 주소가 변경될 경우 앱 업데이트 없이 설정 메뉴에서 주소만 수정하여 영구적으로 사용 가능.
*   **모던 UI/UX**: Material 3 디자인 가이드 준수 및 세련된 그라데이션 테마 적용.

## 🚀 사용 방법 (Usage)

1.  **만화 탐색**: 메인 화면에서 카테고리를 선택하거나 상단 검색창에 제목을 입력하세요. (키보드 '검색' 버튼 활용 가능)
2.  **회차 선택**: 만화 상세 페이지에서 회차 리스트를 확인하세요. 스크롤을 내리면 이전 회차들이 계속 로드됩니다.
3.  **뷰어 조작**:
    *   **전체 화면**: 상단 아이콘으로 진입, 이미지 **길게 누르기(Long Press)**로 해제.
    *   **페이지 이동**: 화면 오른쪽 클릭(다음), 왼쪽 클릭(이전) 또는 스와이프.
    *   **확대**: 두 손가락을 벌려 확대하고 손가락으로 이동하며 상세 내용을 확인하세요.
4.  **다운로드**: 회차 리스트 우측의 다운로드 아이콘을 누르면 '내 보관함'에 저장됩니다.
5.  **로컬 파일**: 메인 하단의 '로컬 zip 파일' 버튼을 눌러 소장 중인 압축 파일을 선택하세요.

## 📝 릴리즈 노트 (Release Notes) - v1.0.0

### [New Features]
*   최초 정식 버전 출시.
*   웹툰 스트리밍 및 사전 다운로드 기능 구현.
*   Pinch-to-zoom 및 3가지 보기 모드(한장/두장/나눠보기) 지원.
*   중첩 ZIP 파일 구조를 완벽 지원하는 로컬 파일 뷰어 추가.
*   Base URL 동적 변경 및 SharedPreferences 영구 저장 기능.

### [Improvements & Bug Fixes]
*   검색 결과가 없을 시 상단 메뉴가 파싱되는 오류 수정.
*   뷰어 하단 슬라이더 레이아웃을 컴팩트하게 조정하여 가독성 향상.
*   안드로이드 6.0(Marshmallow) 이상 기기와의 호환성 최적화.
*   검색 시 키보드 엔터키 반응 로직 추가.
